# shibaoliu.github.io

Personal academic website. Static HTML generated by `build.py` (Python 3 standard library only).

## Update the site

1. Edit `data/site.json` (bio, links, news strip, education, honors, teaching) or `data/papers.json` (papers).
2. Run `python3 build.py`. This regenerates every `.html` page, `feed.xml` and `sitemap.xml`.
3. Preview: `python3 -m http.server 8000`, then open http://localhost:8000.
4. Publish: `git add -A && git commit -m "Update site" && git push`. GitHub Pages redeploys in about a minute.

Never hand-edit the generated `.html` files; the next build overwrites them.

## Common edits

- **Add a paper:** copy an entry in `data/papers.json`. `status` is `review`, `working`, `progress`, or `published`. Fill `ssrn`, `pdf` (e.g. `papers/pdf/file.pdf`), or `journal` to show those buttons; empty fields stay hidden. A paper gets its own page when it has an abstract or presentations.
- **News strip:** `news` in `data/site.json`. Point `paper` at a slug, or give `title` for non-paper items.
- **Profile links:** fill the empty `url` fields (Google Scholar, SSRN, ORCID, LinkedIn) in `data/site.json`.
- **Photo:** put a portrait (4:5, about 520x650) at `photos/portrait.jpg` and set `"photo": "photos/portrait.jpg"`.
- **CV PDF:** save it as `cv/CV_Shibao_Liu.pdf`. Until it exists, the CV button links to the CV page.
- **Colour:** change `--accent` at the top of `assets/site.css`.
